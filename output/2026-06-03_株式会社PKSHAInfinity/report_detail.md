## 2. 組織・カルチャー

### 2-1. 企業理念

- **ミッション**: 「とにかくやってみる、から世界を変える」
- **ビジョン**: 「ワクワクするしごと。」
- **理念**: 失敗を恐れずに挑戦し、失敗経験をナレッジとして蓄積・共有する文化。「失敗をフロー化して全員が学べる仕組み」を重視。
- 親会社PKSHA Technologyのグループ理念: 「人と共進化する未来のソフトウエアを社会に実装していく」
- **出典**: [PKSHA Infinity ミッション・ビジョンページ](https://infinity.pkshatech.com/mission)、[PKSHA Technology ニュース](https://www.pkshatech.com/news/20250318/)

### 2-2. 意思決定スタイル

- **組織構造**: 小規模スタートアップ（62〜75名）。従来の技術領域別組織からプロダクト単位の機能ごとに責任を持つ「プロダクトエンジニア構造」へ移行中。
- **スタイル**: OpenWorkの口コミに「トップのワンマン経営」との指摘あり。一方でAI駆動開発や裁量度の高い働き方も推進しており、実態は確認要。
- **出典**: [OpenWork - PKSHA Infinity口コミ](https://www.openwork.jp/one_answer.php?vid=a0A2x00000AzGuX&qco=1)、[Green Japan - プロダクトエンジニア求人](https://www.green-japan.com/company/7355/job/317126)

### 2-3. 評価制度

- PKSHA Technologyグループ全体として、360度評価（上司・同僚・部下が評価者）を採用。
- 目標設定・評価は半年ごとに実施（グレード制）。
- PKSHA Infinity単体での評価制度の詳細は公開情報から確認できず。
- **出典**: [PKSHA Infinity採用FAQ](https://infinity.pkshatech.com/recruit/faq)、[PKSHAグループ採用情報](https://www.pkshatech.com/recruitment/)

### 2-4. 人的構成

- **従業員数**: 約62〜75名（直近半年で約20名採用し75名に拡大との情報あり）
- **設立**: 2019年10月23日

## 3. 職務・スキル

### 3-1. 業務範囲・チーム

- 主力プロダクト「YOMEL」の機能別開発チームで活動（プロダクトエンジニア構造）
- エンジニアはAIエージェント（Claude Code等）との協働を前提とし、設計判断・品質保証・成果責任に集中
- 主な業務領域:
  - 要件整理・仕様定義
  - AIエージェントへの指示（プロンプト・コンテキスト提供）
  - 設計判断・コードレビュー（AIと協働）
  - リリース判断・本番環境モニタリング
  - ユーザーフィードバックに基づく改善サイクル推進
- **出典**: [Green Japan - プロダクトエンジニア求人](https://www.green-japan.com/company/7355/job/317126)、[Green Japan - AI駆動開発エンジニア求人](https://www.green-japan.com/company/7355/job/295983)

### 3-2. 技術スタック

| カテゴリ | 内容 |
|----------|------|
| 言語 | Python、TypeScript、JavaScript、HTML/CSS |
| フロントエンド | Vue 3、Nuxt |
| バックエンド | Django、Django REST Framework（DRF） |
| DB | MySQL、PostgreSQL |
| ミドルウェア | Redis |
| インフラ | AWS（EKS、RDS 他）、オンプレ（データセンター） |
| IaC | Terraform |
| CI/CD | GitHub Actions、ArgoCD |
| モニタリング | Datadog |
| API仕様 | OpenAPI |
| AI開発ツール | Claude Code、Cursor、Codex CLI |

- **出典**: [Findy - PKSHA Infinityエンジニア求人](https://findy-code.io/companies/2608/jobs)、[Green Japan - プロダクトエンジニア求人](https://www.green-japan.com/company/7355/job/317126)

### 3-3. 教育・研修

- PKSHA Technologyグループとして隔週エンジニア勉強会、学習カリキュラム、海外カンファレンス参加支援あり（グループ全体施策）
- PKSHA Infinity単体での研修制度の詳細は確認できず
- AI駆動開発（Claude Code/Cursor活用）を業務の中心に据えているため、最先端AI開発手法を習得できる環境
- **出典**: [PKSHAグループ採用情報](https://www.pkshatech.com/recruitment/)

### 3-4. キャリアパス

- エンジニアとしての成長は技術と事業の両面で支援される可能性（小規模ゆえに幅広い経験）
- OpenWorkの退職理由に「事業開発のキャリアを選択したが、活躍の幅はエンジニアとしてのみ」との声あり → 非エンジニア職へのキャリアチェンジは難しい可能性
- グレード制で半年ごとに昇給・昇格機会あり（グループ基準）
- 将来的にPKSHAグループ他社への異動・連携の可能性も（グループ子会社）
- **出典**: [OpenWork - 退職理由口コミ](https://www.openwork.jp/one_answer.php?vid=a0A2x00000AzGuX&qco=8)、[PKSHAグループ採用情報](https://www.pkshatech.com/recruitment/fabric/)

## 4. 労働条件・環境
