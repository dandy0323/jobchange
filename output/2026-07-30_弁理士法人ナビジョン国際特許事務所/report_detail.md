## 2. 組織・カルチャー

### 2-1. 企業理念

- **事務所名の由来**: 「Navigate（ナビゲート）」＋「Vision（確かな目）」= ナビジョン。確かな目で顧客の知財戦略をナビゲートすることが使命
- **代表メッセージ（求人票より）**: 「専門性で選ばれる組織」にしたい。規模を追うのでなく一件一件の仕事の質を高めること。長く信頼され続けることが軸
- **文化**: 地道・細かい作業を重視。コツコツと積み上げる文化。論理よりも確認・ルール遵守を重んじる
- **出典**: [リクナビNEXT 求人票](https://next.rikunabi.com/viewjob/jk9af9f58ca7dc0834/)（2026-07-30）

### 2-2. 意思決定スタイル

- **組織構造**: 代表弁理士（石川 克司）のもとで、弁理士＋知財スタッフが分業する小規模法人
- **スタイル**: 「互いに確認し合い、相談しながら進める落ち着いたチームワークのある職場」と求人票に明示。専門職であっても一人完結でなくチーム協働を重視
- **コミュニケーション**: 「気軽に質問できる環境が整っています」と明示（未経験者への配慮を強調）

### 2-3. 評価制度

- **昇給**: あり（求人票に記載）
- **賞与**: 年2回＋業績・実績に応じた決算賞与（業績連動）
- **口コミ記載**: 「賞与は1月分」（エンゲージより確認）—求人票の「年2回」との金額感として年60〜70万円程度が現実的水準の可能性
- **弁理士試験手当**: 短答式試験合格者に月額2万円、弁理士試験合格者にはさらに月額3万円（合計5万円）追加。ただし「所内規定により支給しない場合あり」という条件付き
- **成果報酬**: 給与例に「月給30万円＋成果報酬→年900万円」（5年目）とあり。成果報酬の算定基準は非公開

### 2-4. 人的構成

- **代表弁理士**: 石川 克司（商標・意匠分野の専門家）
- **従業員数**: 非公開（求人票上の情報なし）。年間300件超の商標登録を処理できる体制は数名〜十数名規模と推定
- **法人化**: 2023年8月1日（複数の弁理士が在籍する弁理士法人化）
- **中途入社**: 50%以上（求人票の「仕事の特徴」に記載）
- **女性活躍**: 「女性が活躍中」（求人票に記載）、産休取得実績あり

## 3. 職務・スキル

### 3-1. 業務範囲

**求人票に記載の具体的な業務（商標・知財スタッフとして）:**

① **ヒアリング**
- お客様がどのような権利取得を希望しているかを整理
- 取得可能な権利範囲・登録期間・費用などをご説明

② **商標調査**（専門性の核となる業務）
- 識別性の有無の判断
- 先行商標との類否判断
- 「どうすれば登録可能性を高められるか」を検討・提案

③ **商標登録出願**
- オンラインで特許庁へ出願
- 出願準備・入力は事務スタッフが担当
- 内容確認・判断が主な役割

**未経験スタートの場合:**
- 弁理士の指示のもとで商標調査報告書の作成補助、出願書類の作成補助からスタート
- 段階的に専門性を身に付けながら担当案件を持てるようになる

**扱う業種:** アパレル、化粧品、健康食品、飲食チェーンなど幅広い業界。海外商標（中国・台湾・アメリカ・欧州）にも対応。意匠分野にも挑戦可能

### 3-2. 技術スタック

- 特許庁のオンライン出願システム（J-PlatPat等）
- 商標調査データベース（Jプラットフォーム等）
- 一般的なOffice系ツール
- 知財系特化ツールは詳細非公開

### 3-3. 教育・研修

- **入社後3〜6ヶ月の研修**: 弁理士の指示のもとで実務を学ぶ体制（OJT中心）
- **試用期間**: 3〜6ヶ月（期間中は月給22万円）
- **資格取得支援**: 弁理士試験の受験を支援（手当・環境整備）
- **求人票のキャリア説明（1年目〜3年目）**:
  - 1年目: 商標調査・出願書類の作成補助。商標の審査基準や審査実務を理解しながら一つ一つの案件を丁寧に処理する力を身につける
  - 2年目: 案件の流れを理解し、担当として案件を任される場面が増える。顧客とのやり取り・登録可能性の検討にも関わる
  - 3年目: 商標調査・出願・対応の一連の実務を理解し、一人の専門職として自信を持って案件に向き合えるようになる

### 3-4. キャリアパス

**提示されている年収例（弁理士試験受験生ルート）:**
| 入社年次 | 属性 | 月給 | 年収目安 |
|---------|------|------|---------|
| 1年目（未経験） | 弁理士試験受験生 | 25万円 | 約400万円 |
| 3年目（未経験入社） | 弁理士試験受験生 | 30万円 | 約600万円 |
| 5年目（未経験入社） | 弁理士試験受験生 | 30万円＋成果報酬 | 約900万円 |

- **弁理士取得後**: 弁理士資格取得で月額3万円の追加手当（条件付き）。代理業務独立も視野に
- **専門性の市場価値**: 商標実務経験は他の特許事務所・企業知財部への転職にも有効な市場価値を持つ

## 4. 労働条件・環境

### 4-1. 労働時間

- **所定労働時間**: 9:00〜17:30（休憩1時間・実働7時間30分）
- **勤務形態**: 固定時間制（フレックスなし）
- **残業**: 「ほぼありません」（求人票に明示）。定時退社を基本とした働き方を推奨
- **平均勤務日数**: 1ヶ月あたり20〜22日
- **残業手当**: 支給あり（万が一残業が発生した場合の保証）

### 4-2. リモートワーク

- 「スタッフが安心して長く働けるようリモート勤務など柔軟な働き方を導入」という公式情報あり（詳細不明）
- 求人票にはテレワーク・在宅勤務の具体的な記載なし
- 特許事務所の実務上、機密案件を扱うため在宅の範囲には制限がある可能性
- **要確認**: テレワークの具体的な頻度・条件

### 4-3. 福利厚生

| 項目 | 内容 |
|------|------|
| 社会保険 | 雇用・労災・健康・厚生年金（完備） |
| 交通費 | 公共交通機関使用分（月5万円を上限） |
| 残業手当 | 支給あり |
| 昇給 | あり |
| 賞与 | 年2回（業績連動）＋決算賞与（業績に応じて） |
| 産休 | 取得実績あり |
| 資格取得支援 | 弁理士試験手当（短答合格：月2万円、試験合格：月3万円追加） |
| 食事補助 | チケットレストランと提携（試用期間終了後） |
| 職場見学 | 随時実施 |
| 転勤 | なし |

### 4-4. 給与

| 区分 | 内容 |
|------|------|
| 基本給（本採用後） | 月25万円〜50万円 |
| 試用期間中 | 月22万円（3〜6ヶ月） |
| 固定残業代 | なし（超過分は別途支給） |
| 賞与 | 年2回＋決算賞与（業績連動） |
| 口コミ参照 | 「賞与は1月分」（エンゲージ） |

- **留意点1**: 「月給25万円は未経験で入社した方の最低保証額」と求人票に明示。経験・スキルに応じて決定
- **留意点2**: 固定残業代なしは透明性が高い（残業ゼロ前提の設計）
- **留意点3**: 試用期間3〜6ヶ月（月22万円）は長め。本採用移行の基準を確認したい

## 追加留意事項（求人票に書かれていないが要確認）

- 現在の在籍スタッフ数・弁理士数が非公開。小規模事務所のため、主要スタッフへの依存リスクあり
- 弁理士法人化が2023年8月と比較的最近であり、法人としての制度・文化が発展途上の可能性
- 商標調査は「識別性・類否判断」という高度な専門的判断を伴い、未経験者が完全習得するまでの道のりは求人票の記載（3年）よりも個人差が大きい可能性あり
- 弁理士試験は合格率約6〜8%の難関国家試験。試験合格を目指す場合は長期的な学習継続が前提となる
